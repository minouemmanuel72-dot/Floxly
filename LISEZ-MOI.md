# Floxly – paquet (front lot 3 + installation écran d'accueil)

À la RACINE du dépôt GitHub : index.html, config.js, sw.js, manifest.webmanifest, vercel.json
et le dossier icons/ (5 fichiers). Rien d'autre n'est nécessaire sur GitHub.

Supabase (SQL Editor, dans l'ordre) : 01, 02 (déjà faits), 02b (correctif, déjà fait), 03_floxly_lot3 (nouveau).
Fluxus : supabase/functions/fluxus/index.ts à coller dans Edge Functions (secret ANTHROPIC_API_KEY).

Installer sur le téléphone : un bandeau s'affiche tout seul sur l'écran de connexion et l'accueil.
- Android (Chrome) : bouton « Installer ».
- iPhone : Safari > Partager > « Sur l'écran d'accueil » (le bandeau l'explique).
- Si le lien est ouvert dans Instagram/WhatsApp/Facebook/TikTok : le bandeau demande de l'ouvrir dans Safari ou Chrome.
